Comprobaciones git grep solicitadas por Deber2
Código 1 en grep significa ninguna coincidencia, no error de implementación.

Domain sin React
$ git grep -n from 'react' -- src/domain/
(sin coincidencias)
Código: 1

Concretos fuera de data solo main
